# Question rules (example)

Rules for finding, wording, and ranking buyer questions. The notes and reviews in this starter are invented. Replace the rules with your team's approved process. A proposal cites a rule by its ID.

- `qrule-objection-first`: mine objections and hesitations before anything else. Read the call notes and themes first, then turn each objection into the question a buyer would type into Google or ChatGPT. Reviews and support tickets are extra sources.
- `qrule-confirmed-quote`: a call quote counts only when it meets `call-confirmed` in `brain/call-rules.md`. An unconfirmed quote is a gap.
- `qrule-buyer-words`: write the question in words a buyer used. A product name or internal term is allowed only when the buyer said it.
- `qrule-one-question`: one question per row, 5 to 20 words, ending in a question mark.
- `qrule-source-required`: every question names the review IDs, quote IDs, or theme file it came from. A question with no source is a gap and is not proposed.
- `qrule-no-company-name`: leave the company name out, unless the buyer compares two named companies.
- `qrule-merge-duplicates`: two questions with the same buyer intent (the same doubt, in the same buyer words) are one question, merged before any page is assigned. Keep the clearer wording and list both sources.
- `qrule-rank-sources`: rank by the number of distinct sources that raise the question: unique company domains for calls, unique reviews for reviews. A tie goes to the more recent source.
- `qrule-page-fit`: each question names one site page that answers it. When a question needs an approved fact that no brain file holds, list the gap beside it.
